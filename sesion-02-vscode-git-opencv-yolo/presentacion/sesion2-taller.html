PARTE B · Nivel 4ENTRENAR (RÁPIDO)

Entrenar es más fácil de lo que parece

El modelo que ya descargamos, yolo26n.pt, viene pre-entrenado con el dataset COCO: ya reconoce 80 objetos comunes (personas, autos, animales...).

Para enseñarle algo nuevo — como un tomate — no empezamos desde cero: partimos de ese mismo archivo y le seguimos enseñando (esto se llama fine-tuning).

→ 80 clases ya aprendidas (COCO)

→ la "n" de yolo26n = "nano": la versión más chica y rápida

terminal
$ pip install ultralytics
$ yolo train model=yolo26n.pt data=tomates.yaml epochs=50
entrenar.py
from ultralytics import YOLO
model = YOLO("yolo26n.pt") # el mismo que ya usamos
model.train(data="tomates.yaml", epochs=50)
