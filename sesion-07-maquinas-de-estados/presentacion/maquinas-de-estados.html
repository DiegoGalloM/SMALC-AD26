CONCEPTO 1ESTADO

Un estado es lo que estás haciendo ahora

🍄

Mario

CHICO · GRANDE · FUEGO

📱

Tu celular

APAGADO · BLOQUEADO · DESBLOQUEADO

🚁

El dron

EN_TIERRA · DESPEGANDO · VOLANDO · ATERRIZANDO

Regla de oro: siempre estás en UN solo estado a la vez.

Mario no puede ser CHICO y GRANDE al mismo tiempo. El dron no puede estar EN_TIERRA y VOLANDO.

CONCEPTO 2TRANSICIONES

Las flechas dicen cuándo cambias

Cada flecha es una transición: va de un estado a otro y lleva una condición. Si la condición se cumple, cambias de estado.

segundos: 0.0

CONCEPTO 3LA CLAVE

Lo mismo que pasa... depende del estado

🍄

Mario toca un hongo

Si es CHICO → pasa a GRANDE.
Si ya es GRANDE → solo gana puntos.

🚁

Presionas "despegar"

Si está EN_TIERRA → despega.
Si ya está VOLANDO → no pasa nada (no hay flecha).

Por eso el dron necesita recordar en qué estado está: es una variable.

CONCEPTO 4DEL DIBUJO AL CÓDIGO
la receta de TODAS las lecciones
estado = "EN_TIERRA"          # estado inicial

while dron.sigue():
    s = dron.sensores(estado) # ¿qué sé ahora?

    if estado == "EN_TIERRA": # ① ¿dónde estoy?
        dron.quieto()         # ② lo que hago
        if s.tecla == "t":    # ③ ¿flecha?
            estado = "DESPEGANDO"

    elif estado == "DESPEGANDO":
        dron.despegar()
        if s.en_el_aire:
            estado = "VOLANDO"
①

Una bolita = un if estado == ...

Cada estado tiene su propio bloque.

②

Una acción dentro

Lo que hace el dron mientras está en ese estado. Ya viene escrito.

③

Una flecha = un if condición:

estado = "OTRO". Esto es lo que tú escribes hoy.

LECCIÓN 4 · Ojos con estadosEL ESTADO PERDIDO

¿Por qué no regresar directo a BUSCANDO?

Si alguien pasa frente a la cámara un instante, el dron pierde el color... ¡y empezaría a girar como loco!

El estado PERDIDO espera 2 segundos con s.segundos. Si lo vuelve a ver, sigue como si nada.

lecciones/04_ojos_con_estados.py
elif estado == "PERDIDO":
    dron.quieto()
    if s.veo_color:
        estado = "SIGUIENDO"
    # ✏️ COMPLETA: si s.segundos > 2 -> "BUSCANDO"

Pruébalo: tapa la cámara un segundo y destápala.
