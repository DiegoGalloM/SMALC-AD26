# SMALC AD26

Repositorio central de **SMALC** (Sin Miedo A La Corriente) — el programa de divulgación de ciencia y tecnología de [VANTTEC](https://www.vanttec.com/#/smalc), Tec de Monterrey.

Este repo funciona como **hub**: aquí viven los materiales de las sesiones de los talleres y, más adelante, los retos que se vayan implementando para que los participantes sigan practicando.

## Estructura

```
SMALC-AD26/
└── sesion-02-vscode-git-opencv-yolo/   # Materiales de la Sesión 2 (VSCode, Git, GitHub, OpenCV, YOLO)
```

Cada sesión o reto vive en su propia carpeta, con su propio README explicando qué hay adentro y cómo usarlo.

## Cómo usarlo

- **Si eres participante de un taller:** entra a la carpeta de tu sesión — ahí está la presentación, las actividades y el código base que necesitas.
- **Si vas a agregar una sesión o reto nuevo:** crea una carpeta nueva a este mismo nivel, con su propio README siguiendo el mismo formato.

## Créditos

Mantenido por el equipo de VANTTEC como parte de SMALC.
